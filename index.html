NEED TO KNOW

Frequently asked questions

Do I need to create an account?

No. This website interface does not require visitor sign-in.

Can I download private Pinterest content?

No. Private, restricted or inaccessible content should not be downloaded. Use only content you own or have permission to save.

Why doesn't the Download button download a file yet?

The website design is ready, but a legitimate download service/API has not been connected. The button will not pretend a download has happened.
